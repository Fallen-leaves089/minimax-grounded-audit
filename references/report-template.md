# 报告模板

```text
# 项目健康审计

## 先做这三件事

1. ...
2. ...
3. ...

## 一句话结论

...

## P0

- [标题]
  证据：file:line 或 command
  影响：
  建议：
  验证方式：
  置信度：已验证 / 观察到 / 推断

## P1

...

## P2

...

## P3

...

## 已核验无问题的部分

- 检查面：
  证据：
  结果：

## 本轮未覆盖的部分

- 未覆盖项：
  原因：
  补测条件：

## 环境与边界

- MiniMax Code 版本：
- 模型标识与版本：
- 目标路径：
- Bash 实际 cwd：
- Git 基准：
- 权限模式：
- Plan mode / PTC 状态：
- 工具限制：

## 记忆

记忆：新增 N 条，重复 M 条（<外部记忆路径>）
```

## 输出要求

- “先做这三件事”最多 3 条，按影响排序。
- 一句话结论必须包含证据边界，不写“全面通过”。
- 没有 P0 时写“无确定项”，不删章节。
- 每条结论只使用 `已验证 / 观察到 / 推断`。
- 报告不得包含密钥、个人路径、客户数据或目标原文。
